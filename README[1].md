# Landing “Duplicamos tu carga”

Versión estática lista para GitHub y Vercel. No necesita instalar dependencias ni ejecutar una compilación.

## Antes de publicar

En `index.html`, reemplazá el enlace del botón de WhatsApp por tu número real. Formato recomendado:

```text
https://wa.me/549341XXXXXXXX?text=Hola%2C%20quiero%20recibir%20el%20doble%20de%20mi%20carga
```

El número debe contener código de país y código de área, sin `+`, espacios ni guiones.

## Configuración en Vercel

- Framework Preset: `Other`
- Build Command: dejar vacío
- Output Directory: dejar vacío o usar `.`
- Install Command: dejar vacío

Después elegí **Deploy**.
